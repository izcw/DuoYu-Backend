# 账号头像与宝塔 Go 项目（2026-10-30）

## 头像

- 管理端顶栏通过已验证会话的 DuoYu-ID UserInfo 返回头像；用户管理、同步管理列表使用同一个 UserAvatar 组件显示圆形头像和昵称，缺失或加载失败回退本地默认头像。
- 后端在线验证普通用户身份时同步更新 backend_users.picture；历史账号在下次发起同步/访问业务 API 后自动补齐，不直接访问账号中心数据库。当前管理员头像无需等待业务同步。
- 仅接受 HTTPS 头像地址，不代理任意地址、不把账号令牌传给图片服务器；图片请求不发送 referrer。CSP 允许 HTTPS 图片加载。

## 宝塔

原反向代理项目（ID25）已经移除。使用宝塔原生 create_project 创建 Go 项目 duoyu_backend（ID26），运行用户 duoyu-backend，开机启动开启，域名 sync.duoyu.link 直接绑定此 Go 项目，保留 HTTPS 证书。宝塔仍会在内部通过 Nginx 接入域名，这属于 Go 项目的正常域名绑定实现，无需另建反向代理项目。

- Go 端口：127.0.0.1:5262，目录 /www/wwwroot/duoyu-backend-go。
- Node 同步引擎：原来的127.0.0.1:5260，数据和文件位置不变。
- 旧 Go systemd 服务已停用，避免与宝塔重复启动。宝塔原生重启方法验证通过。
- 恢复脚本会自动识别宝塔 Go 部署，调用面板停止/启动项目，避免仅停止旧 systemd 服务而遗漏实际运行的进程。旧版部署继续使用原 systemd 方法。
- 迁移前已备份面板数据库和站点配置至 /www/backup/duoyu-go-migration-20261030。
