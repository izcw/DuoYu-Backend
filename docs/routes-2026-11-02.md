# 管理系统与 API 路由

- 管理入口：`https://sync.duoyu.link/`，支持管理页面的直接访问和刷新。
- 管理静态资源：`/assets/`、`/logo.png`、`/avatar-default.svg`。
- 管理 API：`/api/admin/…`。
- 同步、附件、模板、目录和网址元数据 API：`/api/v1/…`。
- 登录和回调：`/auth/…`，登录成功后返回 `/`。OIDC 回调地址不变。
- 健康检查：`/healthz`。

不兼容旧 `/v1/…` 和 `/admin/` 地址；扩展需重新加载本次构建的 `.output/chrome-mv3`。扩展的 `VITE_SYNC_URL` 仍为域名根地址，业务路径由客户端统一使用 `/api/v1/…`，不要在环境变量后重复添加 `/api`。

验证：Go 测试与 vet、17 项同步引擎测试、管理端构建和桌面/移动端 UI 测试、扩展类型检查和构建、云同步客户端及 PostgreSQL 集成测试通过。线上根页面及登录跳转通过 Edge 无头浏览器检查；新接口未认证返回 401，旧地址返回 404。未使用真实用户账号执行新的登录授权。
