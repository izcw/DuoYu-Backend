# 管理端优化与回归测试（2026-10-30）

## 修复和界面

个人配额为空是因为 quota_bytes=null 表示继承全局默认，但原界面直接绑定空数字。现在显式区分跟随默认和单独设置：继承时显示全局实际值，输入框不可编辑；单独设置支持0至102400整数MB，空值不能误保存成0或继承。界面显示生效容量、已用空间、进度及超额说明。切换模式重新建立数字控件，消除 Element Plus 数字控件保留禁用状态的问题；移除路由跳转后的旧行表单赋值，避免覆盖最新设置。

后端用户设置接口返回姓名、头像、默认配额、生效配额和已用字节。用户不存在返回404。继承配额仍保存null，避免将全局默认值固化为个人额度。0MB禁止新增上传，不删除文件。

文件列表增加懒加载缩略图、格式、大小、上传时间；点击图片或预览按钮打开站内弹窗，显示完整图片、像素尺寸及文件标识，支持加载中和失败状态。所有图片读取继续使用同源管理员Cookie鉴权接口、私有缓存策略和访问审计，没有生成公开用户文件链接。

统一用户信息头部、容量卡片、中文状态标签、表格空状态、分页间距、移动端弹窗和底部操作区域，沿用已有DuoYu-ID公共样式。新增FilePreview组件。

## 测试结果

- Go后端7个集成测试全部通过：管理员边界、CSRF、签名身份、版本冲突、并发配额、文件隔离/迁移、模板初始化、头像、继承/自定义/零配额、非法配额、管理员文件预览和普通用户拒绝访问。
- go vet通过，清理一处旧测试中无效的fmt.Sprint调用。
- Node同步服务16项测试全部通过。
- 管理端类型检查及生产构建通过。
- Edge桌面/手机自动化通过：导航、图表、头像、模板创建/默认模板、未保存提醒、继承→自定义→0MB→恢复默认、私有图片缩略图和站内预览；390px弹窗无页面横向溢出，无脚本异常。
- 扩展cloud:client、cloud:integration、cloud:ui、cloud:account-ui、conflict-preview全部通过；覆盖双/三设备离线编辑及重连、重试幂等、冲突处理、JSON导入、附件失败重试、真实PostgreSQL持久化。扩展类型检查通过。
- Go race检测未运行：本机没有CGO所需的C编译器。普通并发配额及同步事务测试已执行；不能将其等同于race检测。
